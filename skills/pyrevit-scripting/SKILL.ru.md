# Скрипты и кнопки pyRevit

Используйте `pyrevit-script-assistant` для выбора движка и транзакций. Сохраняйте структуру существующего расширения.

UTF-8; при неизвестном движке — совместимость с IronPython 2.7. Для CPython первая строка `#! python3`. `engine.clean` не выбирает Python 3. Документ получайте заново при каждом запуске.

Порядок: собрать элементы → показать изменения → разрешить отмену → выполнить транзакцию → проверить → сообщить результат. Метаданные кнопок поддерживают русский и английский. Шаблон из assets — заготовка, а не готовый инструмент.
