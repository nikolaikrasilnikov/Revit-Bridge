# Чертежи DWG / DXF

В комплекте находятся помощники для DXF. Для DWG требуется отдельный установленный конвертер; его бинарник не распространяется.

Инвентаризация: `dxf_survey.py`; геометрия: `dxf_segments.py`; проверочная отрисовка: `render_segments.py`. Перед запуском смотрите `--help`. Зависимости: ezdxf, shapely, matplotlib.

Подтвердите единицы, пространство модели/листа, блоки, преобразования вставок и внешние ссылки. Проверьте опорные размеры и план. Замкнутый контур сам по себе не доказывает помещение; внутренний контур не обязательно шахта.
