# Code Mode

[English](CODE_MODE.md)

Code Mode — основной интерфейс агента, реализованный в Revit Bridge. Это выполнение JavaScript-сценария внутри MCP-сервера; отдельная установка не нужна. Реализация создана для этого продукта: найденные исходники прежнего Code Mode не заявляются.

| Слой | Задача |
| --- | --- |
| `revit_tools` | Поиск среди 28 операций и получение точных JSON-схем; по умолчанию пять на страницу |
| `revit_code_mode` | Выполнение тела асинхронной JavaScript-функции с циклами, await и обработкой JSON |
| `revit.call(name, args)` | Проверка аргументов и вызов существующего обработчика операции |
| Мост Revit | Очередь API-операций в основном потоке Revit; проверки транзакций и документов |

Перед незнакомой операцией вызовите `revit_tools` с `{"query":"revit_query"}`. Пустой запрос показывает каталог; переходите по `nextOffset` или задайте `limit:28`, если нужен весь список. Рекурсивный вызов Code Mode не предоставляется.

## Примеры

Передайте это тело функции в поле `code` инструмента `revit_code_mode`:

```javascript
const sessions = await revit.call('revit_sessions', {});
return sessions.map(s => ({ sessionId: s.sessionId, year: s.year }));
```

Для точного UUID сеанса из предыдущего ответа:

```javascript
const sessionId = '12345678-1234-4234-8234-123456789abc'; // замените реальным UUID
const queued = await revit.call('revit_documents', { sessionId });
const job = await revit.call('revit_job', { sessionId, jobId: queued.jobId, waitMs: 1000 });
return job; // queued/running ещё не означают завершение
```

Внешний язык — JavaScript. C# передаётся в поле `code` операций `revit_query` и `revit_execute_code` вместе с точными UUID сеанса/документа и прежними параметрами транзакции. Готовый пример чтения — `examples/code-mode-discover.json`:

```powershell
node server/probe.mjs revit_code_mode examples/code-mode-discover.json
```

## Выполнение и восстановление

- Ожидайте каждый `revit.call` через await. Вызовы отправляются последовательно, в том числе из `Promise.all`. Для зависимых шагов используйте обычный цикл.
- Аргументы проходят исходные Zod-схемы и обработчики. Предпросмотр, сохранность элементов, предупреждения, резервирование и явные разрешения на сохранение/экспорт сохраняют прежнее поведение. Если request UUID отсутствует, сервер назначит его до вызова операции.
- Ответ содержит `runId`, `status` сценария, JSON `value` или `error` и краткий журнал вызовов с UUID сеанса/запроса/задания/пакета. `completed` означает возврат JavaScript, а состояние нативных заданий проверяется отдельно.
- Ограничения: 64 000 символов кода, 32 вызова, 10 секунд по умолчанию (настраивается от 100 до 30 000 мс), 1 МиБ на ответ операции и 256 КиБ на итоговый результат. Используйте страницы и возвращайте сводки. Лимит old-generation heap worker — 64 МиБ; это не предел всей памяти процесса.
- Таймаут или отказ worker останавливает дальнейшие вызовы JavaScript. Уже отправленные задания не отменяются, предыдущие commit не откатываются, резервирование не снимается, повторы не запускаются. Незавершённый вызов отмечается `unknown`; используйте его UUID, `revit_job`, состояние пакета и чтение модели для сверки. requestId очереди является jobId; requestId порционного моделирования является batchId.
- JavaScript-сеанс и его ответ не сохраняются на диск. Отправленные задания Revit сохраняются. После потери ответа MCP или отключения проверяйте очередь и модель; не повторяйте сценарий вслепую. Для восстановления при потере ответа передавайте стабильные requestId явно.
- У каждого вызова свой контракт транзакции. Несколько вызовов в сценарии не образуют общую атомарную транзакцию. Длительное моделирование запускайте через `revit_model_chunks`, затем читайте состояние, результаты и контрольные точки.

Выполняйте только доверенный код, подготовленный агентом. Worker и VM-контекст ограничивают выполнение и предоставляют фасад `revit`; API process, модулей, файлов и сети не предоставляются. Node VM не является защитной песочницей для враждебного кода. Ограничения внешних эффектов C# описаны в [контракте выполнения](EXECUTION.ru.md).

Дополнительно каждый синхронный участок JavaScript ограничен одной секундой. Тяжёлые вычисления выполняйте при внешней подготовке данных; у заданий Revit свой контракт нативного выполнения.

## Совместимость

По умолчанию MCP показывает только `revit_tools` и `revit_code_mode`. Задайте `REVIT_BRIDGE_TOOLSET=full` в окружении MCP-сервера, чтобы показать 28 прежних прямых инструментов и два основных. Значение по умолчанию — `code`. После смены окружения переподключите MCP-клиент. Дополнительные pyRevit/.NET-компоненты не нужны; нативный мост не изменён.
