# Нативное моделирование Revit

Сначала прочитайте `revit-bridge`. По свежему состоянию установите документ, единицы, фазы, уровни, семейства и преобразования исходной геометрии.

Создавайте нативные элементы подходящих категорий. Проверяйте материал, тип, хозяина, отметки и смещения отдельно. Изменение общего типа затрагивает все его экземпляры.

Фиксируйте метку операции, ID и UniqueId. После commit заново считайте элементы и проверьте фактические размеры, положение, связи, дубли и предупреждения. При таймауте сначала сверяйте уже созданное. Импортированный mesh не выдавайте за нативную модель. Сохранение — отдельная операция.
