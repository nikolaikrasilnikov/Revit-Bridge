# Контракт выполнения

Основной вход — Code Mode: `revit_tools` находит схемы операций, а `revit_code_mode` выполняет JavaScript с `await revit.call(name, args)`. Все операции используют прежние проверяемые обработчики. Таймауты, квитанции и полный набор инструментов описаны в [Code Mode](CODE_MODE.ru.md).

- Выбирайте точные UUID сеанса и документа; обновляйте после открытия и перезапуска.
- Чтение защищено от записи; preview откатывает модель. Внешняя транзакция принадлежит хосту.
- API Revit выполняется последовательно в допустимом callback основного потока. Разбор файлов выносится отдельно.
- Порции фиксируются независимо. Поздняя ошибка или отмена не отменяет прежние commit.
- При неизвестном исходе сверяйте исходный job и модель; не повторяйте запись вслепую.
- Контроль ID/UniqueId дополняйте независимым чтением параметров и геометрии после commit.
- Сохранение, экспорт и закрытие — отдельные явные инструменты.
- Файлы, сеть, reflection и процессы не изолированы транзакцией Revit.
- Предупреждения по умолчанию приводят к откату. Поддерживаемое исключение требует фактического разрешения; ошибки и проверки сохранности остаются.
- Изменения в памяти, сохранённый RVT и экспортированный IFC — разные результаты.

У кнопок и необязательного хоста pyRevit отдельные контракты движка и транзакций. Защиты C#-моста не распространяются автоматически на обычные Python-кнопки.
