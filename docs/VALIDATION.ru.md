Эта среда запрещает fs.link и создание junction; протокол владения заданиями опирается на эти операции и не ослаблялся ради тестов. Полный набор с Code Mode прошёл на обычных Windows/Linux runners в [GitHub Actions, запуск 43080306258](https://github.com/nikolaikrasilnikov/Revit-Bridge/actions/runs/43080306258), коммит `cb19b89`. В Windows тестовые временные пути приведены к каноническому виду, чтобы учитывать сокращённые имена 8.3.

Рабочие модели не открывались, не изменялись и не сохранялись. Тест установки не регистрировал надстройку в настоящем профиле Revit. Действующая интеграция осталась без изменений.

Code Mode реализован и проверен через MCP-протокол. Работа с живой моделью Revit через него пока не проверялась; полный нативный цикл на чистом компьютере не заявляется. C#-мост в версии 0.2.0 не менялся.
