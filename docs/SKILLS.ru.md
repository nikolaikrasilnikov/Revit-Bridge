# Навыки

Устанавливайте каталоги целиком. SKILL.md — точка обнаружения агентом; SKILL.ru.md — русский вариант.

| Навык | Назначение |
| --- | --- |
| revit-bridge | Сеансы, документы, чтение/изменение и проверка через MCP |
| revit-native-modeling | Нативные элементы по подтверждённой геометрии |
| pyrevit-script-assistant | Движки, транзакции, отладка и заготовки |
| pyrevit-scripting | Расширения, метаданные, шаблоны и API-рецепты |
| fbx-obj-reference | Состав сцены, единицы и привязка |
| pdf-drawings-parse | Векторный PDF, тексты, калибровка и DXF |
| dwg-plans-parse | Состав и геометрия DXF; для DWG нужен отдельный конвертер |

Разбор исходников работает во внешнем Python. Перед запуском смотрите --help. Наличие помощника не доказывает проверку всех ветвей формата в текущем выпуске.
