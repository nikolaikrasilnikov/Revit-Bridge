# Skills

Install complete directories. SKILL.md is the discovery entry point; SKILL.ru.md is the Russian companion.

| Skill | Purpose |
| --- | --- |
| revit-bridge | Sessions, documents, protected queries/edits and verification |
| revit-native-modeling | Native elements from confirmed geometry |
| pyrevit-script-assistant | Engine compatibility, transactions, authoring and scaffolding |
| pyrevit-scripting | Bundles, metadata, templates and API recipes |
| fbx-obj-reference | Source scenes, units and transforms |
| pdf-drawings-parse | Vector PDF, positioned text, calibration and DXF |
| dwg-plans-parse | DXF inventory and geometry; DWG requires external conversion |

Reference helpers run in external Python. Read each helper's --help. Inclusion is not a claim that every format branch has been exercised in this release.
