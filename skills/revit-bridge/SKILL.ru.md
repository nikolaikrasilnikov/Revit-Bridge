# Revit Bridge

Используйте уже подключённый MCP. Сначала получите актуальные сеанс и документ, затем прочитайте модель и реальные возможности моста.

Основной вход — Code Mode. Найдите JSON-схему операции через `revit_tools`, затем вызовите её внутри JavaScript инструмента `revit_code_mode`: `await revit.call('revit_sessions', {})`. Имена ниже относятся к операциям этого фасада; прямой полный набор включается отдельно. C# передаётся в поле `code` операций чтения/изменения, а не на верхнем уровне. Ожидайте каждый вызов и возвращайте краткий JSON. Завершение JavaScript не означает завершение задания Revit. После таймаута сохраняйте requestId/jobId из ответа и сверяйте результат без автоматического повтора; для записей с риском потери ответа задавайте стабильный requestId явно.

- Чтение: `revit_query`; код — C#, переменные `document`, `uiapp`, `parameters`.
- Изменение: `revit_execute_code`; внешний Transaction принадлежит мосту, для подгруппы используйте SubTransaction.
- Предпросмотр: `preview` с откатом. Массовая обработка независимых элементов: `revit_model_chunks`.
- Проверяйте результат отдельным чтением после commit. Сверяйте геометрию, параметры и предупреждения, а не только счётчик.
- После таймаута проверяйте тот же job и модель; не повторяйте запись автоматически.
- Сохранение и экспорт выполняются отдельными явными командами. Отчёт различает изменения в памяти, сохранённый RVT и экспорт.

Работу с API выполняет основной поток Revit. Тяжёлые вычисления и разбор файлов выносите за его пределы. Полная техническая инструкция: SKILL.md.
