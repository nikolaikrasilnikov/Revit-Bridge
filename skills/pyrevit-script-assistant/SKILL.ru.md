# pyRevit Assistant

Создание, отладка и проверка кнопок pyRevit и автоматизации Revit API. Полная техническая инструкция: SKILL.md.

Сначала установите поверхность выполнения, версию Revit, фактический движок и владельца транзакции. Используйте существующее подключение; не включайте другой MCP-хост ради написания скрипта.

Проверьте категории, фазы, тип/экземпляр параметров, GUID, единицы и доступность записи. Для неизвестного движка сохраняйте совместимость с IronPython 2.7. Внешний Transaction принадлежит кнопке либо хосту — это разные контракты.

После commit заново прочитайте элементы. Проверяйте нужные параметры, геометрию и связи. Счётчик без ошибок не доказывает результат. После таймаута не повторяйте запись без сверки job и модели. Различайте изменения в памяти, сохранение RVT и экспорт.

Скрипт `scripts/scaffold_pyrevit_button.py` создаёт безопасную заготовку; перед использованием смотрите `--help`. Замените пример готовой логикой требуемой кнопки.
